# MindEase React UI

This project recreates the 10 screens shown in the supplied MindEase reference image using React, React Router, CSS and Lucide icons.

## Screens
1. Welcome
2. Login
3. Home
4. Mental Health Information
5. Self-Screening
6. Mood Tracker
7. Journal
8. Self-Care
9. My Progress
10. Get Support

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Notes
- The UI is responsive and uses a mobile-phone presentation on larger screens.
- Navigation between the screens is already wired with React Router.
- The screening, mood selection and login button include basic demo interactions.
- Replace demo text/data and connect your backend APIs where needed.
